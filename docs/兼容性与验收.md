# 兼容性与验收

首版为 `v0.1.0-beta.1` 预览版。构建成功只代表代码能够编译，不代表每一种 Windows / Word 组合都已经完成排版验收。下表分别记录目标范围和实际证据，发布前只根据真实结果更新。

| 环境或入口 | 首版范围 | 当前记录 |
|---|---|---|
| Windows 11 x64 + 桌面 Word | 已实测 | Windows 11 x64，构建 26200；Microsoft Word x64 16.0.20527.20088 |
| Windows 10 x64 + 桌面 Word | 待逐版本验证 | 尚未完成独立环境测试，不笼统承诺全部 Windows 10 版本 |
| 32 位 Office / x64 Windows | 待实际验证 | 进程外 COM 架构可互操作不等于已实测 |
| 64 位 Office / x64 Windows | 已实测 | 上述组合完成真实安装、恢复与重启验收 |
| 无 Python、未额外安装 .NET 的干净 Windows | 待干净虚拟机测试 | 已通过仅保留 Windows PATH、指向不存在外部 .NET 目录的自包含包启动检查；这不等于干净虚拟机验收 |
| Word 内“空白文档”或 Ctrl+N | 核心入口 | 未指定模板的 Documents.Add 已完成两组、每组两次独立 Word 启动检查 |
| 资源管理器右键“新建 Word 文档” | 单独记录 | 未完成实际入口测试时不得视为通过 |
| 使用其他 DOTX / DOTM 创建文档 | 由对应模板控制 | 修改 Normal 不代表改变这些模板 |
| 已有 DOCX | 副本导入 | 保留直接格式及非目标自定义样式，导入不等于全篇排版合规 |
| WPS、Mac、Word 网页版、32 位 Windows、ARM 原生包 | 不在首版范围内 | 不提供兼容承诺 |

## 必须完成的核心检查

- 26 项目标样式和 12 项常用入口与公开规格一致。
- 文档除样式部分外的包内内容保持一致，包含宏、快捷键、正文、公式及图片对应部分。
- 验证自定义样式 ID、中文/英文内置名称、依赖映射、缺失默认节点和不可识别冲突。
- 相同配置重复安装不改写；安装前后哈希及备份可核对。
- 文件占用、目标并发变化、损坏包和包级签名不会导致静默覆盖。
- DOCX 副本文件名不覆盖既有文件，导入前后的原件 SHA-256 相同。
- 恢复会检测安装后修改，并保护当前版本。

## Word 实际验收

默认正文检查中文宋体、英文 Times New Roman、12 磅、固定 20 磅行距及首行 2 字符。标题检查四级大纲及字体字号，图题和表题检查不同段后间距。使用两次独立 Word 启动及未指定模板的空白文档创建流程，排除只验证独立 DOTX 的误判。

示例文档应检查三级自动目录、四级导航、字体实际显示和全部页面渲染。缺失字体必须按受影响样式报告，不将替代字体呈现算作通过。旧文档副本需检查原件不变、公式/图片仍在，并说明直接格式的保留。

## 发布验证

公开资产必须来自实际验收的同一次构建。上传后使用未登录下载重新核对文件大小和 SHA-256。未完成的环境、入口、代码签名或其他验收项目列在对应 Release 说明中，预发布标签不代表所有兼容性项目已经完成。

验收记录只发布系统/应用版本、测试项目和结果，不发布个人模板、真实论文、完整私人路径或原始操作日志。

## v0.1.0-beta.1 实际验收记录

2026 年 10 月 25 日完成：

- 14 组核心测试通过，涵盖中文样式 ID、同名冲突、标题编号关联、非样式部件保留、幂等、锁冲突、并发变化、恢复确认及 DOCX 副本。
- 真实默认模板完成安装、两次独立启动验证、重复安装、恢复原始文件校验、再次安装及再次两次独立启动验证。
- 常用库的 12 个实际 Word 样式名称保持简洁；正文、四级大纲和图表题间距通过检查。
- 真实模板仅 `word/styles.xml` 改变；原有 7 项快捷键和其他包内内容逐项一致。恢复后文件 SHA-256 与安装前完全相同。
- 现有楷体_GB2312 重复导入没有改写；篡改后的字体字节被拒绝，已安装字体继续通过实际字库核验。
- 公开示例的 8 页已渲染并逐页检查，未见遮挡、裁切或缺字；目录和图表清单页码与内容一致。
- 修复后的公开 DOTX 和 DOCX 均通过 Microsoft Word 实际打开；示例在内存更新三级目录后仍为 8 页，Word 原生导出的全部页面也逐页检查通过，未保存回公开原件。
- 已有 DOCX 的迁移测试原件 SHA-256 不变，副本仅改变样式部件；Word 实读保留 1 个原生公式、1 张图片、手工加粗斜体和字号、自定义样式及一级标题大纲。

尚未完成：Windows 10 独立环境、32 位 Office、干净 Windows 虚拟机、资源管理器右键新建入口。可执行文件尚未进行 Authenticode 代码签名，因此首版维持预发布状态。
