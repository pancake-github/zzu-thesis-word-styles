## 来源与补充默认值

学校规范明确的字体字号、标题级别、行距与段前后要求按给定文件提炼；把完全相同的格式归并为共享样式是本工具的整理方式。下列三项为已确认的补充默认值，不能写成学校原文规定：

| 使用位置 | 已确认补充默认值 |
|---|---|
| 中英文摘要正文 | 与正文合并，采用两端对齐、首行缩进 2 字符 |
| 参考文献、符号说明、简历及成果等附属正文 | 两端对齐、首行缩进 0 字符 |
| 致谢正文 | 两端对齐、首行缩进 2 字符 |

规范未单独明确的默认 0 值、目录条目的两端对齐、具体制表位位置、样式继承关系、常用库排序、黑色/非斜体的显式写入、孤行控制关闭、网格与自动更新开关，是本实现的明确默认或控制机制，不等于学校逐项规定。完整属性树为了可复核而保留这些值。

一级标题、中文摘要标题、英文摘要标题及目录标题采用段前分页，以落实各部分从新页开始的要求。四级标题保留导航大纲；示例自动目录只收录前三个级别。标题编号在示例中作为文字输入，不安装自动多级列表。

封面六种样式为字符样式，只改变选中文字的字体字号；沿用学校封面的原有布局。它们本身不创建完整封面、校徽、声明页或签名区域。
