# 郑大学位论文样式助手

为 Windows 桌面 Microsoft Word 配置一套精简的郑州大学论文样式。下载、解压后运行中文助手，即可检查字体、配置新建文档的默认样式、给已有 DOCX 的副本导入样式，并从备份恢复。

**这是非官方的文字与段落样式工具。** 规范依据为研究生院 [2024 年 4 月 25 日发布的附件](https://gs3.zzu.edu.cn/info/1045/13029.htm)，所用规范文件落款为 2023 年 9 月。项目区分学校明文要求与已确认的补充默认值，不代替学校审查，也不自动完成整篇论文排版。

## 第一次使用

1. 将整个 ZIP 解压到一个普通文件夹，保持程序与附带文件在一起，双击 `ZZUWordStyles.exe`。
2. 先查看环境检查结果，确认 Word、字体和模板状态。检查功能不会修改 Word 默认模板。
3. 保存正在编辑的文档并关闭所有 Word 窗口，在助手中选择配置默认样式。助手会先备份再写入，记录安装前后的校验值。
4. 完成后运行 Word 实际验证，或打开 Word 并新建空白文档。默认正文应为中文宋体、英文 Times New Roman、12 磅、固定 20 磅行距、首行缩进 2 字符。

界面操作与各状态的含义见 [使用指南](docs/使用指南.md)。仅使用独立模板时，可解压模板包，双击 `郑大论文样式.dotx` 创建文档，并另存为自己的 DOCX。

> 修改默认模板不会自动修改以前保存的文档。已有文档仍保留自身样式和直接格式。

## 已有文档怎样使用

在助手中选择 DOCX 导入入口。程序生成 `原文件名_郑大样式.docx`，已有同名文件时自动追加编号，原件保持不变。正文内容、图片、公式、直接格式和非目标自定义样式均保留。

已有段落若使用“正文”“标题 1”等对应样式，会获得更新后的样式定义；直接指定的字体、字号或缩进可能仍覆盖它。助手会报告此类设置，**不会自动清除有意保留的加粗、斜体、公式格式或自定义排版**。自定义段落样式需要自行选择对应的论文样式。

## 包含哪些样式

共有 **26 项样式**，常用样式库显示 **12 项**：正文、标题 1—4、中文摘要标题、英文摘要标题、目录标题、图题、表题、附属正文、致谢正文。封面字符样式、目录条目、页眉页码等低频项目可从样式面板调用。

| 示例 | 格式 |
|---|---|
| 正文 | 中文宋体、英文 Times New Roman，12 磅，固定 20 磅行距 |
| 标题 1—4 | 黑体，16 / 14 / 13 / 12 磅，保留四级标题导航 |
| 英文摘要标题 | Arial，18 磅，加粗；这是本版规范所列格式 |
| 图题与表题 | 宋体，10.5 磅；段后分别为 12 / 6 磅 |
| 致谢正文 | 仿宋，12 磅，固定 16 磅行距 |

完整参数及依据见 [样式对照表](docs/样式对照表.md)，机器可读配置见 [style-spec.json](assets/style-spec.json)。示例包含三级自动目录和四级标题；模板不自动建立标题多级编号。

安装保留接收者的页面尺寸、页边距、页眉页脚布局、宏、快捷键和构建基块。独立模板自身带有一组示例页面设置，不能据此认定整篇论文已满足所有页面要求。目录页码制表位也需结合实际页面宽度检查。

## 字体

本项目不附带任何字体文件。缺失字体会影响相应样式的实际显示，助手不会静默替换字体或修改系统字体替代规则。

封面需要 `楷体_GB2312`，它与现代“楷体”不能仅凭名称混用。可通过 [校方附件页面](https://www5.zzu.edu.cn/student/info/1003/13037.htm) 手动下载，出现验证码时由用户完成；再在助手中选择已下载的 ZIP 或 TTF。助手仅接受已核实的字体文件，并按当前用户安装，同时保留已有“楷体”。详见 [字体与第三方说明](THIRD-PARTY-NOTICES.md)。

## 备份、隐私与边界

备份只保存在本机。恢复前会检查默认模板是否在安装后发生变化，避免静默覆盖后来新增的设置。已有文档导入始终生成副本，不覆盖原文件。程序在本地处理文档，不上传论文内容；新版本由用户主动下载。

遇到“正文仍显示等线”、安装未生效或恢复问题，请先看 [FAQ](docs/常见问题.md)。反馈问题时可提供错误信息和 Word 版本，不要上传真实论文、个人 Normal.dotm 或含私人路径的原始日志。
